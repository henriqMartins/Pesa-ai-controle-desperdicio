# Controle de Desperdício — Petiscaria

Aplicativo web (PWA) para registrar e acompanhar o desperdício de alimentos de
uma petiscaria.

A documentação completa está em [`docs/`](docs/):

- [Visão geral e como rodar](docs/README.md)
- [Arquitetura](docs/arquitetura.md)
- [Modelo de dados](docs/modelo-dados.md)
- [Setup do ambiente](docs/setup.md)
- [Documento base original](docs/base.md)

## Início rápido

```bash
npm install
cp .env.example .env.local   # preencha com a URL e a anon key do Supabase
npm run dev
```
