# Controle de Desperdício — Petiscaria

Aplicativo web (PWA) para registrar e acompanhar o desperdício de alimentos de
uma petiscaria.

A documentação completa está em [`docs/`](docs/) — comece pelo
[índice da documentação](docs/README.md):

- [Produto](docs/produto.md) — o que faz e por quê
- [Arquitetura](docs/arquitetura.md) e [modelo de dados](docs/modelo-dados.md)
- [Setup](docs/setup.md) e [infraestrutura/deploy](docs/infraestrutura.md)
- [Testes](docs/testes.md) — como rodar os testes automatizados

## Início rápido

```bash
npm install
cp .env.example .env.local   # preencha com a URL e a anon key do Supabase
npm run dev
```
