1 · Visão geral

O sistema possui dois níveis de filtragem, independentes entre si:

  • A Mini-filtros de painel — chips rápidos no canto de cada painel (Últimos lançamentos, Produtos desperdiçados, Principais motivos). Filtram por período pré-definido sem sair da tela.
  • B Modal de filtros avançados — aberto pelo botão “Filtrar”. Cruza produtos, valores e datas com três modos de análise e um seletor de período flexível.
2 · Mini-filtros de painel

Cada painel guarda seu próprio estado de período. Os chips ativos ganham destaque (pílula branca no modo claro, laranja no escuro).

Helpers de período (logic class)
isYesterday(ts) { // mesmo dia do calendário de ontem }
sameDate(ts, str) { // bate com uma data YYYY-MM-DD }

periodFilter(arr, p, dateStr) {
  if (p === 'hoje')  return arr.filter(l => this.sameDay(l.ts));
  if (p === 'ontem') return arr.filter(l => this.isYesterday(l.ts));
  if (p === 'mes')   return arr.filter(l => this.sameMonth(l.ts));
  if (p === 'outra') return arr.filter(l => this.sameDate(l.ts, dateStr));
  return arr; // 'total'
}

Cada painel chama periodFilter(launches, state.fX) em renderVals(), e agrega o resultado por produto/motivo. Subtítulos e totais de rodapé são derivados do mesmo período.

3 · Modal de filtros avançados

Aberto por openFiltros → state.modal = 'filtros'. Estrutura: seletor de modo + seletor de período + área de resultado reativa.

1 Mais registrados fxMode: 'topProd'

Agrupa lançamentos por produto e ranqueia pela quantidade de ocorrências no período. Cada linha mostra barra proporcional e valor total acumulado.

2 Maior valor fxMode: 'topValor'

Ordena os lançamentos individuais pelo valor de cada registro. Destaca o maior em um card-herói (produto, quantidade, motivo, data e valor) seguido do ranking completo.

3 Por produto fxMode: 'porProduto'

Escolhe-se um produto no <select> e lista todas as datas em que ele foi registrado dentro do período, com rodapé somando ocorrências e valor total.

Seletor de período — fxRange()
fxRange() { // devolve [inicio, fim] em ms
  if (fxPeriod === '7d')    return [now - 7*day, now];
  if (fxPeriod === '30d')   return [now - 30*day, now];
  if (fxPeriod === 'mes')   return [inicioDoMes, now];
  if (fxPeriod === 'range') return [fxFrom, fxTo]; // de/até
  return [0, now]; // 'total'
}

// filtra a base uma única vez, reusada pelos 3 modos
const [a, b] = this.fxRange();
const within = launches.filter(l => l.ts >= a && l.ts <= b);

Opções de período: 7 dias · 30 dias · Mês · Total · Período (personalizado de/até com calendário). O array within é calculado uma vez e alimenta os três modos — troca de modo não recalcula o recorte de datas.

Todo cálculo vive em fxVals(), espalhado dentro de renderVals(). O template apenas exibe: <sc-if> alterna o modo visível e <sc-for> percorre as listas. Cada modo tem estado vazio dedicado quando não há dados no período.

5 · Checklist para novos filtros
  1. 1 Adicionar o campo ao state inicial com valor padrão.
  2. 2 Escrever/estender o helper de recorte (período ou agregação).
  3. 3 Expor a lista pronta + flag de vazio em renderVals().
  4. 4 Montar chips/select e a área de resultado com sc-if/sc-for.
  5. 5 Conferir estado vazio e o comportamento nos dois temas (claro/escuro).
